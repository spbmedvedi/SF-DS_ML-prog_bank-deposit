### Описание проекта    
 Анализ данных банка о последней маркетинговой кампании, задачей которой было привлечение клиентов для открытия депозита, выявление закономерностей и поиск решающих факторов, повлиявших на решение клиентов о вложении дополнительных  денежных средств непосредственно в этот банк.


### Какой кейс решаем?    

**знакомство с данными:**  
- предварительный анализ и загрузка данных банка в IDE (VSCode);
- исследование структуры и эвристический анализданных.

**Первичная обработка и разведывательный анализ (EDA) данных**     
- обработка пропусков и выбросов;
- определение первичных закономерностей; 
- выдвижение гипотез;
- отбор и преобразование признаков.

**Решение задачи классификации клиентов банка**
- построение прогностических моделей логистической регрессии и решающих деревьев с оценкой их качества;
- построение прогностических моделей ансамблей моделей с оценкой их качества;
- подбор оптимальных параметров моделей;
- определение наилучших гиперпараметров.

### Краткая информация о данных
Все необходимые данные для проведения анализа и построения прогностических моделей принадлежат реальному банку и находятся в **data/bank_fin.csv**
  

### Этапы работы над проектом  
1. Первичная обработка данных
2. Разведывательный анализ данных
3. Отбор и преобразование признаков в данных банка
4. Решение задачи классификации: логистическая регрессия и решающие деревья
5. Решение задачи классификации: ансамбли моделей и построение прогнозов
6. Выбор  модели, обеспечиваюшей наиболее качественные прогнозы, и определение её оптимальных параметров (гиперпараметров)
7. Оформление выводов по качеству разработанных прогнозных моделей
8. Оформление документации для отправки проекта на GitHub 


## Результаты:  
Результаты положительные. Анализ представленных банком данных и разработка прогнозных моделей по классификации клиентов банка проведены успешно. В целом решена важная бизнес задача - определены характеристики,
по которым можно выявить клиентов, более склонных к открытию депозита в банке, и за счёт этого повысить результативность маркетинговой кампании.
